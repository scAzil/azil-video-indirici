# AZiL Video İndirici

Windows için yt-dlp tabanlı hafif başlangıç sürümü. Klasik `BASLAT.bat` ve kaynak paketi ZIP dosyaları `downloads/` altında yayımlanır.

**Durum:** Yeniden hazırlanmış 0.2 başlangıç paketi; önceki `AZiL_Video_Indirici_v1.zip` dosyasının birebir aynısı değildir. Windows'ta canlı indirme henüz doğrulanmadı. Python 3.10+ ve ilk çalıştırmada internet gerekir.

- Çalıştırma paketi: `downloads/AZiL_Video_Indirici_Calistir.zip`
- EXE hazırlama paketi: `downloads/AZiL_Video_Indirici_Hazirlama.zip`

Yalnızca indirmeye yetkili olduğunuz içeriklerde kullanın.
